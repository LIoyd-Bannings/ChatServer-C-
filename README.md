# ChatServer-C++-
工作在nginx tcp负载均衡环境中的集群聊天服务器和客户端源码 基于muduo库实现，涉及redis、mysql
编译方式 
cd build
re -rf *
cmake ..
make

基于Ubuntu系统 需要配置nginx、redis、muduo等。
==================================================================================================================================================================================================
已经进行第一步优化：实现添加Mysql连接池组件。
在引入连接池前后，针对 10 线程并发、总量 100万条请求的压测对比：
|         指标           |     无连接池       |           有连接池           |           提升效果       |
|------------------------| -------------------| :--- ------------------------| :-----------------------|
|   QPS (Client Send)   | ~0 (大量失败/超时)  |              33,282          |    由不可用转为高性能     |
|   Server Valid QPS    |   < 10 (严重阻塞)   |           稳定高吞吐         |    消除 DB 连接瓶颈       |
|   DB Connect 开销     | 每次请求都需要握手   |       0 开销   (启动即复用)    |      100% 连接复用率    |
|   平均耗时 (Latency)   |    3.0s+ (超时)     |           0.017 ms           |         毫秒级响应       |

**优化结论**：通过连接池技术，消除了 TCP 三次握手和 MySQL 认证的巨大开销，成功解决了高并发下的连接耗尽和超时问题。
